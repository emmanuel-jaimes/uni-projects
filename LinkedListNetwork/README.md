READ ME:

The purpose of this application is to collaboratively manipulate and manage a linked list. Adding, removing, and rearranging the order of the elements as one or more desire

How to run program:
1. Run Server File
2. Run Client File
   3. View the menu options prompted within the Client
      4. The first menu option is to simply view the status of the linked list and order of its elements
      5. The second menu option is to insert an element into any position of the linked list
      6. The third menu option is to remove any element in any position of the linked list
      7. The fourth menu option is to shut down connection with the server
   4. Seperated by a space in the textfield, enter the data in order of [Menu Prompt] then [Element to be inserted/removed] and finally [Desired Position]
   \n Example Usage:
      1. To insert an element into the linked list enter command "2 3 4" Where "2" selects command insert, "3" represents element to be inserted, and "4" represents position where element is to be added
      2. Same format for removing elements but instead selecting the "3" menu command
5. Once process is complete, close connection to Server
